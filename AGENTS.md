# UI design

For UI design and review, use the downloaded Apple Design skill at
`skills/apple-design/SKILL.md`. Route topics with
`skills/apple-design/references/hig-lookup.md` and read the applicable references.
Apply the foundations to this React web app; native macOS conventions are
inspiration, not requirements for browser behavior.

The UI-only review route is `/design-preview`. It must use fictional in-memory
data, remain visibly labeled as a preview, and never call authenticated or live
lookup endpoints. Keep the real application behind its existing authentication.
